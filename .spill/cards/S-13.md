## Purpose
Make the golden rule (D-10) checkable: each page of a document holds information the other pages do not. The validator should catch the overlaps a machine can see, so authors and the authoring skill cannot ship them.

## Requirements
1. A term is defined on one page only. Defining the same term on two pages is an error naming both places.
2. A later page may mark a term that an earlier page defines; the reader opens the earlier definition (labelled with the level it comes from) instead of the page carrying its own copy.
3. A sentence that appears (after normalising case and spacing) in the paragraphs, definitions or explainers of two pages is an error naming both places.
4. Two pages whose figures have the same set of part kinds and captions are an error (the second page repeats the first).
5. The AI coding agent test fixture is rewritten to follow the rule (its main page currently redefines tools, context window and tool call from L2).

## Out of scope
- Judging overlap of meaning in different words; that stays with the authoring skill (S-11) and the reader.

## Acceptance checks
- A document defining "tokens" on L1 and L2 fails with both paths.
- A sentence copied from L1 into the main paragraph fails with both paths.
- The fixed fixture passes, and its main page term popups for L2 terms show L2's definitions.
