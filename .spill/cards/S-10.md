## Purpose
A document can be sent to anyone and opened offline in any browser, with nothing to install.

## Requirements
1. Exports a document as a single self-contained HTML file: reader, figures, fonts and data inline, no network requests.
2. Source links stay as normal links; they are the only thing that needs the network.
3. The file opens and works fully in current Chrome, Safari and Firefox from a file:// path.
4. The export fails with the validator's messages if the document is invalid.

## Out of scope
- Hosting, accounts, analytics.

## Acceptance checks
- The example exports to one file that works with the network off (apart from source links).
- The file is under 2 MB.
