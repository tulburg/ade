## Purpose
One file that holds everything a reader needs for one concept: the main concept, up to two prerequisite levels, their explanations, figures and sources. The reader, the figure kit and the authoring tool all read and write this one format.

## Requirements
1. A document is one JSON file (`.ade.json`) described by a JSON Schema in the repo (D-4). A document has: a main concept (title, paragraph, figure) and 0 to 2 prerequisite levels, in reading order. More than 2 prerequisites is invalid.
2. Each prerequisite level has: an id (L1, L2), a cover question ("Do you fully understand X?"), a title, a paragraph and a figure. The main concept has no cover question.
3. A paragraph is text with two kinds of marks: terms (a word or phrase that has a definition) and references (a number pointing at a source). The plain text stays readable with the marks removed.
4. Every term has a definition: a full explanation in plain words, an optional pointer to a figure part, and at least one source.
5. Every reference number points at a source in the level's source list: title, kind (doc, pdf, paper, video, page) and URL.
6. A figure has parts. Each clickable part has a tag unique in its level (A1, C2), a caption of 5 to 8 words, an explainer (what it is, how it connects, sources) and its drawing data.
7. "How it connects" entries cite other parts by tag, including parts on another level as `L1 A2`. Every cited tag must exist.
8. Connections between parts have a tiny note (at most 5 words).
9. At most 3 parts per figure are marked as moving, each with a motion description.
10. A validator checks the file against the JSON Schema and the cross-reference rules above (tags exist, counts, word limits), reporting each broken rule with its JSON path; a document that fails is not opened by the reader.

## Out of scope
- How figures are drawn (S figure kit); how documents are produced (authoring); the share bundle.

## Acceptance checks
- The worked example (How an AI coding agent works, with L1 and L2) is written in the format and passes the validator.
- Documents with 3 prerequisites, a missing tag, a 4th moving part, a caption of 9 words, or a term with no definition each fail the validator with a message naming the place.
