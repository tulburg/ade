How an AI coding agent works
An AI coding agent is a language model run in a loop with tools. Your request goes into its context window, the working memory that holds everything the model can see: its instructions, your task, the files it has read and the result of every step so far.[1] On each step the model reads the whole context and answers with text or a tool call, a structured request such as edit_file(auth.ts).[2] The program around the model, the harness, runs that tool against your code and appends the result to the context. The loop repeats (read, act, observe) until the tests pass or the model decides the task is done. Nothing is remembered outside the context, so when it fills up, older steps are summarized to make room.[3]
