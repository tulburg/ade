What a language model does
A language model writes by predicting. It splits the text so far into tokens, short pieces of words that each map to a number, and passes them through a stack of transformer layers. Every layer uses attention to weigh each token against every other, so a word is read in the context of the words around it.[1] The last layer turns this into a probability distribution: odds for every token in a vocabulary of about 100,000. The model samples one of them, and the temperature setting decides how adventurous that pick is; a low value almost always takes the likeliest token.[2] The chosen token is appended to the text, and the whole loop runs again on the longer text. Writing a paragraph is this loop repeated, one token at a time.[3]

Attention×
The step inside each layer that decides which other tokens matter for this one. In “the cat sat on the”, the next word leans on “sat on” far more than on “the”. Attention gives each pair of tokens a weight and mixes their meanings by those weights.
